# 🕹️ Mario-Style Platformer (C++ / SFML)

A 2D platformer built using **C++ and SFML**, focused on understanding core game development systems such as the game loop, rendering, and input handling without relying on high-level engines.

## ⚙️ Tech Stack
- C++
- SFML (Simple and Fast Multimedia Library)

---

## 🎮 Features
- Player movement (left/right + jumping)
- Gravity and basic collision handling
- Structured game loop
- Real-time rendering
- Keyboard input system

---

## 🧠 Learning Objectives
This project was built to understand:
- How a game loop works in real-time applications
- Manual rendering using a graphics library
- Event-driven input handling
- Basic physics and collision systems

---

## 🚀 Getting Started

### Prerequisites
- C++ compiler (g++, MSVC, etc.)
- SFML installed and configured

### Build & Run
```bash
g++ main.cpp -o game -lsfml-graphics -lsfml-window -lsfml-system
./game
